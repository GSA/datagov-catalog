Federal Agency Source Code Repositories

The SHARE IT Act (Public Law 118-187) requires federal agencies to make their source code repositories publicly discoverable. This page displays the compliance status for all federal agencies reporting to Data.gov.

Status meanings:

  • Repository URL: Agency has reported their source code repository location
  • Exempt: Agency has an OMB-approved exemption from the SHARE IT Act requirement
  • Not yet reported: Agency has not yet provided repository information to Data.gov
